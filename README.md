# CodeAlpha Artificial Intelligence Internship

This repository contains the projects completed as part of my
Artificial Intelligence Internship at CodeAlpha.

## Tasks Completed

### Task 1 - Language Translation Tool

A web-based language translation application that allows users to
enter text, select source and target languages, and receive translated
text through a translation API.

#### Technologies Used

- Python
- Flask
- HTML
- CSS
- Requests
- Translation API

#### Features

- Text input
- Source language selection
- Target language selection
- API-based translation
- Translated text display
- User-friendly interface


### Task 2 - FAQ Chatbot

An NLP-based FAQ chatbot that matches user questions with the most
relevant FAQ from a predefined dataset.

#### Technologies Used

- Python
- Flask
- Scikit-learn
- TF-IDF
- Cosine Similarity
- HTML
- CSS

#### Features

- FAQ dataset
- Text preprocessing
- TF-IDF vectorization
- Cosine similarity
- Question matching
- Automated responses
- Interactive chatbot interface


## Task 2 Workflow

User Question
↓
Text Preprocessing
↓
TF-IDF Vectorization
↓
Cosine Similarity
↓
Find Best Matching FAQ
↓
Display Answer
